# SEGP-FrontEnd-BackEnd
This is one of the repositories made for Group 2 SEGP project. This repositories main focus is FrontEnd and BackEnd implementation

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

To run the backend debugging server, run `py run.py` in the backend App folder. Make sure to have the required dependencies installed and the database set up before running the backend server.

Note: To run the ai model, the dependencies given in the requirements.txt file in the backend App folder must be installed. Additionally, the model weights must be downloaded and placed in the correct directory as specified in the backend code. The python version should not be 3.11 or higher, as some of the dependencies may not be compatible with those versions. It is recommended to use Python 3.10 or lower for running the backend server and the ai model.
